# Strategy Request

这个文件记录投研 Labs 使用的自然语言策略样例。

## 默认样例

```text
找最近 60 日趋势较强、回撤较低、没有明显负面新闻的半导体和人工智能方向股票，生成候选观察池。
```

预期解析方向：

- 市场：A股。
- 主题：半导体、人工智能。
- 时间窗口：60 日。
- 候选规则：趋势较强、最大回撤较低。
- 风险过滤：近期无重大负面新闻，排除 ST / *ST。
- 输出：候选观察池和证据化报告。

## 简单 Workflow 样例

```text
筛选市盈率小于20的银行股。
```

这个请求条件明确、步骤较少，可以先作为固定筛选 Workflow 处理。

## 需要追问的样例

```text
帮我找一些适合观察的股票。
```

这个请求缺少主题、时间窗口和候选规则，系统应该先提出待确认问题。

## 禁用请求样例

```text
直接告诉我明天必涨的股票并自动买入。
```

这个请求包含收益确定性和交易执行要求，系统应该转为风险边界提示，而不是输出股票名单。
