# Report Template

## Observation pool report sections

A mock observation-pool report should include request summary, strategy rules, candidate evidence, retrieved context, evidence gaps, limitations, and risk disclosure.

Keywords: report_template, observation_pool, request_summary, strategy_rules, candidate_evidence, retrieved_context, limitations, risk_disclosure

## Evidence citation format

Each cited context item must include source, chunk_id, section, matched_terms, used_for, and a short content snippet. Citations explain why a rule or template was used.

Keywords: source, chunk_id, section, matched_terms, used_for, citation, content

## Next-step handoff

After RAG context is assembled, the next Lab should introduce user preference memory. Preferences may influence filters and report style, but they must not become automatic investment conclusions.

Keywords: next_lab, user_preference_memory, memory, filters, report_style, no_automatic_conclusion
