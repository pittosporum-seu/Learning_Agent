# Codex Skill Templates

这里保留两份仓库维护 Skill 的文档模板，用于说明后续维护 Labs 和文档同步时应该遵守的步骤。

这些文件只是模板资料，不是本地 Codex runtime 配置。实际本地工具配置不得提交到仓库，`.agents/` 和 `.codex/` 已加入 `.gitignore`。

This directory contains documentation template files, not local runtime configuration.

## 模板

- [Lab Implementation](lab-implementation/SKILL.md): 修改或新增 Lab 时的维护流程模板。
- [Docs Sync](docs-sync/SKILL.md): 修改文档结构、导航和维护清单时的同步流程模板。
